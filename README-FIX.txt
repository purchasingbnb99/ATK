V3.8 – Purchase Order UI refinement
- PO item rows now use a stable horizontal layout: Barang | Qty | Harga PO | Aksi.
- + Item is placed beside the delete icon in the Aksi cell of the last row only.
- Adding an item moves + Item to the new last row.
- Deleting the last row moves + Item back to the previous last row; an empty form keeps one row.
- PO modal backdrop remains non-dismissable.
- Desktop and mobile layouts remain responsive.
- Backend/database/API configuration are unchanged.
